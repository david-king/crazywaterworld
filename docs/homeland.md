# 家园与工坊

手动入口为 **杂项 → 家园**，自动化入口为 **挂机配置 → 基地 → 家园**。需要支持家园的游戏协议、当前配置表和已连接的账号。开放条件以当前角色、赛季和服务器状态为准；首次开启请在游戏完成家园引导。

页面显示家园等级、家具摆放数量、下一次升级条件、下一项科技、家园币余额与累计消费，以及工坊订单、各楼层打扫进度。刷新只读取状态，不执行游戏操作。挂机配置里的「只读预览」使用当前草稿计算可执行动作。

## 执行范围

- 领取每日免费工坊体力，以及工坊商店的免费每日商品。宝箱进入游戏工坊奖励区，暂不自动取出或打开。
- 提交棋盘上已有足够物品的订单；锁定棋子不计入可交数量。可另开「取出订单所需仓库物品」，在棋盘有空位时逐件取料。
- 开启「按订单需求自动合成」后，用现有棋子补齐订单。订单卡片展示下一步合成、剩余次数或等待原因，也可手动执行单步合成。
- 达到家园等级要求后开放下一层，逐项打扫。打扫会消耗家园币并给奖励。
- 按顺序升级科技，达到目标科技等级、等级门槛、预算或保留量限制后停止。
- 家园升级条件全部满足时升级，达到目标等级后停止。

自动化总开关和所有细项默认关闭，同时受「基地执行总开关」控制。默认每 300 秒检查一次，每轮最多 20 个动作。仅开启每日免费领取时，当日确认完成后停止重复读取；有消费或订单任务时按间隔检查。手动操作不要求开启自动化，但仍受家园币预算和保留量限制。

## 工坊自动合成

在「挂机配置 → 基地 → 家园」开启「自动提交工坊订单」及其下方「按订单需求自动合成」。升级旧配置时，新合成开关保持关闭。需要仓库原料时，还需开启「取出订单所需仓库物品」。

规划优先处理限时订单，并保留其他订单已预留的成品。同一订单内部统一分配用料，允许用现有低级成品参与合成，只在最终能补齐该单所有需求时执行；每一步回读确认后重新规划，齐备后交单。半锁定棋子可作为合成目标，完全锁定格、生产器和体力瓶等可使用物品不参与合成。

规划使用 A* 搜索，以当前订单的合成、存入、取出总次数最少为目标；交单固定增加一次操作，不计入页面的备料步数。同种同状态棋子按数量压缩，实际执行时重新绑定棋子编号。估价忽略空间和半锁定限制，计算必需合成次数的下界；旧规划器提供完整可行方案作为上界，上下界相等即可证明最优。搜索允许重新打开成本降低的状态，避免启发式导致错误的最优结论。

最优性仅针对当前订单、当前仓库权限及成品保留规则，不比较跨订单长期收益，不生产、出售或合成与本单无关的物品。每单搜索最多扩展 12,000 个节点，按 40,000 个已发现状态或 100 毫秒预算停止（在节点边界检查）；有完整方案时显示「可行方案，尚未证明步数最少」，没有完整方案时等待，不执行局部路径。页面与只读预览显示已证明的最少步数，搜索结果有界缓存且不复用旧棋子编号。

合成前联合比较棋盘内合成、仓库取料和中转的总步数。可在「按订单需求自动合成」下开启「使用仓库中转腾位」，同时开启仓库取料。该选项默认关闭，允许暂存闲置普通棋子、稍后才用的原料、中间产物或成品；生产器、体力瓶及锁定棋子保持原位。

中转会模拟整单的存入、取出和合成过程，逐步核算棋盘及仓库容量；只有能完成计划时才开始搬运，按计划逐件存取，不批量清空棋盘。中间产物在参与后续合成前取回，交单前确保全部成品能回到棋盘；暂时用不到的物品留在仓库，后续按订单需求取回，不自动恢复原格子。不购买仓库容量，仓库满、容量未同步或缺少可暂存棋子且无法找到其他完整方案时显示等待原因。材料不足或订单到期时停止该单的合成。

## 家园币与升级条件

**累计消费家园币 = 家具购买 + 科技升级。** 该计数来自游戏，升级后不清零，不等于当前余额。打扫费用不计入游戏升级条件，但计入本工具的每日家园币用量。

新家园升至 2 级需要累计消费 100 家园币，科技在家园 2 级开放。起步阶段请先在游戏购买家具，随后可优先用科技推进累计消费。家园升级还可能要求玩家等级、已通过关卡、指定星级英雄数量，以及家园解锁后获得的功勋。

默认每日家园币预算为 500，保留量为 0。手动和自动打扫、科技共用预算；每日上限设为 0 时禁止家园币消费，免费领取和满足条件的家园升级仍可执行。保存设置或重启不会清零用量。

## 结果确认

消费发送前持久记录目标与额度。请求后回读科技、等级、任务、棋盘或商店状态；涉及家园币还要核对库存。超时不视为成功，也不立即重发。未知结果跨重连、跨日保留，未确认前暂停后续家园操作。

订单消失可能只是到期，因此还要核对该单所需棋子已经消耗。昨日免费领取结果若无法确认，换日后保留未知历史，允许领取新一天的独立免费额度。

合成回读同时核对源格清空、目标格升级与原料消耗；订单到期本身不能确认合成成功。暂不自动生产棋子，不购买付费体力、仓库容量、商品或家具，也不处理装修、英雄入住与拜访。

仓库中转须同时确认源格清空与同编号、同种类的棋子进入仓库；超时后跨重连与跨日保留未知记录，确认前不继续搬运。页面显示仓库用量、计划暂存数量及下一步中转操作。

## 离线验证

`npm run test:homeland` 验证真实协议编解码、业务规则、预算、未知结果、重连、账号队列和 HTTP 边界。`npm run test:homeland:browser` 验证真实控制台页面和手机布局。测试使用隔离数据目录及假游戏服务端，不连接真实游戏账号。
