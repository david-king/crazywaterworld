# 疯狂水世界 · 航行控制台

![Node.js 22.12+](https://img.shields.io/badge/Node.js-22.12%2B-417E38) ![Windows](https://img.shields.io/badge/Windows-本地控制台-0078D4) [![仅供学习交流](https://img.shields.io/badge/license-Study%20Only-orange)](LICENSE)

在本机管理《疯狂水世界》账号，直连游戏 WebSocket，安排领奖、基地经营、英雄养成和舰队任务。支持多账号独立配置、资源预算和运行日志，主要面向 Windows，提供 macOS 基础运行适配。

[快速开始](#快速开始) · [功能一览](#功能一览) · [常用命令](#常用命令) · [使用指南](docs/console-guide.md) · [更新日志](CHANGELOG.md)

## 快速开始

### 1. 安装环境并下载项目

安装 **Node.js 22.12 或更高版本**（也兼容 20.19+ 的 20.x）和 Git，重新打开终端后执行：

```powershell
git clone https://github.com/xutongxue233/crazywaterworld.git
cd crazywaterworld
```

也可下载仓库 ZIP 并解压。一键启动脚本会自动检查并安装项目依赖。项目已通过 `.npmrc` 默认使用 npmmirror 境内镜像，一键启动和手动安装均生效。

### 2. 启动控制台

仓库自带 `protocol/game.js`，下载项目后即可启动，无需安装电脑版微信或导入协议包。有新版 `_src_chunks_.wxapkg` 时，可放到项目根目录或 `protocol/` 目录，控制台也会自动识别本机微信缓存。加载时自动解包并校验，之后移走包仍可使用已缓存的更新。[协议更新与来源顺序](docs/console-guide.md#资源自动更新)

**Windows：** 双击项目根目录的 `start-console.cmd`，或在终端执行：

```powershell
.\start-console.cmd
```

**macOS 或 Linux** 用户可在项目根目录运行启动脚本。

```sh
sh ./start-console.sh
```

脚本会检查 Node.js 和 npm，按需安装依赖，再构建界面。首次安装需要联网。启动后手动打开终端显示的地址，默认为 [http://127.0.0.1:17323/](http://127.0.0.1:17323/)。

手机连到和电脑同一路由器的 Wi-Fi 后，在手机浏览器打开启动窗口显示的 **局域网地址**。如果列出多个地址，选择电脑连接该路由器的 Wi-Fi 或以太网网卡。运行 `.\start-console.cmd address` 可以单独查看地址。[启动参数](docs/console-guide.md#启动参数)

如需**手动启动**，可在项目根目录执行以下命令。

```sh
npm ci --include=dev
npm start
```

`npm start` 构建界面后尝试打开浏览器，默认地址为 [http://127.0.0.1:17321/](http://127.0.0.1:17321/)。一键脚本和 `npm start` 均支持 `CW_PORT`，以终端显示的地址为准。[启动参数与入口差异](docs/console-guide.md#启动参数)

首次启动请保持联网。控制台会检查游戏 CDN 的版本清单，下载并校验配置表和世界地图。之后默认每 30 分钟复查一次，版本一致且本地文件完整时会复用缓存。

控制台打开后会在后台同步图标和贴图，复用已有文件，并按清单从 CDN 补齐缺少的图集。没有电脑版微信也能下载。首次同步期间可继续使用控制台，完成后刷新页面即可看到图标。

如果首次下载失败，可在网络恢复后到项目根目录手动重试。两条命令都完成后刷新页面。

```sh
npm run sync-resources
npm run sync-art -- --fetch
```

### 3. 添加账号并开启挂机

1. 打开 **账号 → 添加账号**，选择微信扫码、支付宝、益世界 APP、电脑微信或电脑抖音采集，按提示登录并保存角色；已有备份可使用 **导入账号**。
2. 新账号的挂机、模块和细项开关默认全部关闭。在 **挂机配置** 中开启需要的项目、设置资源限制；活动专属设置在 **活动** 对应详情中调整。可先用 **只读预览** 查看计划。
3. 点击账号卡片或页头的 **开始挂机**。网页可关闭，请保持启动窗口打开、电脑唤醒；关闭启动窗口或按 `Ctrl+C` 会结束进程。

在 **账号** 页，各账号卡片并排显示角色资料、资源余额和闯关挂机收益。在线账号会自动更新，离线账号显示上次读取的余额和时间。点击任意卡片的 **区服管理**，即可加载该账号的区服、添加角色或进入指定区服。

电脑微信和电脑抖音采集仅适用于 Windows；采集就绪后需从对应客户端重新进入游戏。支付宝扫码会优先复用已有浏览器，找不到时才自动下载 Chromium。[各渠道登录步骤](docs/console-guide.md#添加账号与抓包)

## 功能一览

点击页头「日志」旁的放大镜，或按 `Ctrl+K`（Mac 上为 `⌘K`），可以搜索功能和页面文字。选择结果即可跳到对应位置。

在「运行日志」中，账号选「全部」时，点击「清空」会清除所有账号和系统的运行日志。选中单个账号时，只清除该账号的日志。

具体入口、玩法限制和执行规则见 [控制台使用指南](docs/console-guide.md#功能一览)。

在 **挂机配置 → 世界 → 海盗** 开启「自动挑战下一级」后，每天最多执行一轮首杀，依次挑战海盗先锋、海盗精锐、海盗头目。每类从个人首杀记录的下一级开始，胜利会清零该类连败。达到当前赛季阶段开放的最高等级，或连续战败达到设定次数（默认 3 次），就换下一类。三类都结束后，当天首杀结束，已开启的免费扫荡继续执行。「免费扫荡目标」可多选，并可为每类设置每日次数。正数表示固定次数，0 表示跳过，-1 表示使用剩余免费次数。

同时开启首杀和扫荡时，挂机先检查首杀。已出征的种类会保留应分的扫荡次数，等个人首杀记录更新后再扫新等级。舰队忙于其他任务、战败或战果超过 15 分钟未确认时，按当前已首杀等级扫荡。

博物馆探宝优先安排地图推荐的英雄。需要补位时先选低品质英雄，同品质再选本体与专武合计星级较低的英雄。

在 **挂机配置 → 基地 → 生产 → 工厂 → 禁止自动领取** 中勾选建筑类型，即可留着该类型所有建筑的产物手动领取。例如勾选「冶炼厂」会保留所有冶炼厂的精铁。

在同页的 **需求优先级** 中，拖动需求左侧手柄或点击「上移」「下移」即可调整顺序，松手或点击后自动保存。智能排产开启「按需优先生产」后，把「工厂补料」放在「居民订单」前，共用生产位和原料时会先补库存；把居民订单放在前面，则先为订单备料。

多栋建筑需要同一种材料时，预览按栋备料。材料齐备且允许开工后，该栋的建材会从预计库存中扣除，下一栋可继续使用腾出的仓容。

在 **挂机配置 → 世界 → 万吨巨轮** 中，用“参与时间”限定自动参加、跟随、兜底和追杀。每行填写一个北京时间时段，例如 `22:00-02:00`，可填多段，留空默认全天。

开启“是否开启追杀”后，在“追杀玩家”中按昵称或 ID 搜索对手。名单含战力榜和已有私聊联系人，点「加载下一页战力榜」可继续查找。控制台自动保存勾选角色的 ID，改名后仍能匹配。没有合适的 ID 目标时，按手填的完整昵称兜底。发现对手正在前往、驻守或交战的货轮时，所选空闲舰队会优先追击。“追杀时间范围”可在参与时间内进一步限定追杀时段，追杀去程可单独设置钻石加速和每日预算。

总览按功能列出当前状态和结果，点开一行可查看具体动作。可按名称或原因搜索，也可只看需关注的功能。挂机配置各分组只有一个「运行预览」，默认显示最近挂机记录，点击「只读预览」可查看当前设置下的可排动作和原因。

展开「居民需求」可查看今日已交单数和下一档奖励需要的单数。达到门槛后显示「可领取」，当天所有档位都确认领取后显示「已完成」。

在 **挂机配置 → 日常 → 任务与领奖** 开启「每日任务与奖励总开关」，可分别勾选「领取月卡每日奖励」和「领取赛季卡每日奖励」。挂机和一键领取都会按选择执行。普通月卡和高级月卡分别领取。赛季卡需先在游戏内选满三项自选奖励。

在 **杂项 → 日常任务** 查看当前账号今日进度，点击任务行内的按钮即可执行该项或领取已达标的奖励。需要钻石时会显示金额并单独确认。

在 **挂机配置 → 日常 → 任务与领奖** 展开「闯关挂机收益」，可设置领取间隔，也可独立开启「自动升级挂机等级」。开启收益领取后，间隔填 0 会等到存满再领，填 6 会在累计 6 小时或提前存满时领取。自动升级默认关闭，开启后按游戏按钮的 1、5、10 级档位连续升级，直到用完定位芯片或达到主线允许的等级。

在 **阵容 → 游戏阵容** 可查看主线、各支舰队、远征、跨服积分赛、极限试炼和巅峰擂台赛队伍。点“编辑”调整站位或载入预设，再点“应用到游戏”更新该队。“另存为预设”将搭配保存在当前账号，可在 **我的预设** 中离线查看或用于挑战。读取英雄数据后，头像跟随角色当前装备的皮肤。

在 **总览 → 资源田概览** 点击「查看明细」查看该类全部已占田，按行选择「放弃」。点卡片上的「占领」或「换田」可查看该类全部候选田，每行显示所属城市、等级和建筑名。需要替换时，先点新田所在行的「替换」，再选择旧田。三个列表均按等级从高到低排列。[资源田玩法与策略](docs/resource-fields.md)

城战接续出战没有每日次数上限。多盟同攻时，若攻方队列为空，或已同步的排队舰队明细与攻方队列总数吻合，城战接续可按本盟队数选城。若本盟队数仍无法确认，「按队数与距离选择」会跳过该城，「沿用集结／指定城市顺序」仍可按顺序派舰。

联盟募兵入口为 **挂机配置 → 世界 → 联盟 · 募兵与互助 → 自动在联盟城市募兵**，需同时开启联盟自动化总开关。新赛季没有专属次数配置时沿用不高于当前赛季的最近赛季配置，再按玩家等级取档；异常配置会停止募兵。[规则说明](docs/alliance-automation.md)

## 配置与预算

- **海商王四天预设**。三个方案都优先采购预计回报至少 5% 的货，并在当日可跑完的航线中比较下一港特产的已知紧缺销路。自然航行用 0 根针，免费针方案只动用本期已核实的免费余额，每日最多 100 根、每程最多 4 根，5,000 万达标优先方案整期最多用 220 根针，每天最多 100 根，每程最多 4 根，达到目标后停针。该方案每天等已知紧缺港达到 12 个或 15:00 后再用针。
- **海商王紧缺货估价**。目的港确认紧缺但缺少本港同货报价时，采购和出航会参考本期同品质紧缺货的实价。缺少同品质样本时，用至少两组不同港口或刷新轮次的紧缺报价，取最低实测涨跌幅估价。
- **海商王首日选港**。首次开市前，空船会比较有能力采购的固定特产，优先选开市前可见同盟到船少的港口，再看现有本金与舱位按基准价能买多少货值。条件相同或自然航行赶不上开市时留在本港。
- **海商王隔夜备货**。当天来不及跑完一程且本期次日仍开市时，三个预设按本金和舱位选相对基准价有利润空间的货；手动满舱模式仍优先装满。同价、同基准价、同占舱的两种货，在时间和销港允许时分装。目的港优先避开整船投入本金最多的同种特产，其次考虑可见同盟到船。自然航行赶得上开市就保留指针。收盘前到港的异地货，本港能卖出利润就先成交，再用回款备隔夜货。用针策略为省针追赶、达标优先或仅用免费针时，备隔夜货之前会先核对指南针，够的话改跑一程当天成交的加速航次。次日即使平价或亏损也逐批清舱，再按新行情采购。
- 配置按账号自动保存，保存配置不会开始挂机。**暂停挂机** 停止循环并保留连接；自行进入游戏前使用 **暂停托管**，退出游戏后再 **恢复托管**。
- **海商王指南针**每根缩短 30 分钟。「同港抢先」比较所有可见、驶向同一目的港的同盟船。领先时留针，落后或并列时只用能超过最早一艘所需的根数。「全程加速」在每程、每日和背包保留量允许时尽快到港。可另开「最后一根防抢」，每程剩余 30 分钟即尝试用一根，即使暂时领先或没有可见同港船。到港后按当时库存和价格交易。
- **钻石总开关默认关闭**，每日总预算默认 `2000`，保留量默认 `0`。日预算为 `0` 时暂停受全局开关控制的钻石消费。海商王升船和指南针补购独立于全局钻石开关、日预算和保留量。开启自动升船后以本期满级为目标，按实际余额支付。指南针补购另设每日预算。折扣商店挂机由本模块独立控制，符合购买条件且实际余额足够就会购买。折扣商店挂机购买和手动商店消费均独立记账，不占全局预算。
- **联盟商船补货**由「联盟商船 → 货舱补给」的开关和每日钻石上限独立控制。上限为 `0` 时只用库存，购买前仍会留足账号的钻石保留量。
- 用量和结果未知的操作会持久记录，重启或保存配置不会清空。自动恢复、配置修复和多页面冲突处理见 [配置与预算细则](docs/console-guide.md#配置与预算)。
- 地图上的舰队可以同时显示「主城空闲」和「情报派遣待核对」。控制台会复查原情报和舰队，满足归队、情报状态和 15 分钟等待条件后释放舰队。原情报的防重记录和待确认汽油继续保留。
- 城战留队时，地图会显示上次城战检查得出的待命原因。例如耐久未达标且关闭了自动维修时，可直接看到当前耐久和出战所需点数。

## 数据与问题排查

`data/` 保存账号凭据、设置、账本和日志，更新或迁移前请备份；账号导出文件也含登录信息，请留在本机。遇到启动失败，先看 [启动与排查](docs/console-guide.md#启动与排查)；功能执行异常按 [问题反馈日志](docs/console-guide.md#问题反馈日志) 保留记录。

请只用自己的账号测试。自动化操作会改变游戏资源和进度，第三方工具存在账号处罚风险。电脑客户端采集会临时修改 Windows 用户代理和证书，异常残留可按 [采集异常恢复](docs/console-guide.md#采集异常恢复) 处理。控制台没有登录校验，请在可信局域网中使用一键启动脚本。仅供本机使用时，可用 `--host 127.0.0.1` 启动。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `.\start-console.cmd` | Windows 一键检查环境、按需安装依赖、构建并启动，默认端口 `17323` |
| `sh ./start-console.sh` | macOS 或 Linux 一键启动，默认端口 `17323` |
| `npm start` | 构建界面并启动控制台，默认端口 `17321` |
| `npm run build:ui` | 单独构建页面与样式 |
| `npm run sync-resources` | 检查游戏 CDN 的版本清单，更新配置表和世界地图到 `work/cdn/resources/` |
| `npm run sync-art` | 仅使用本地微信素材缓存同步图标和贴图 |
| `npm run sync-art -- --fetch` | 使用版本清单从 CDN 补齐缺少的图集并更新 `work/cdn/art/` |
| `npm run test:startup` | 检查启动准备、协议来源、监听地址与终端输出，无需游戏账号或真实协议包 |
| `npm run test:offline` | 构建、类型检查并运行核心离线回归，无需本机游戏协议包 |

更新项目时先停止控制台，备份 `data/`，更新源码后重新运行一键启动脚本；手动启动则重新执行 `npm ci --include=dev`、`npm start`。已打开的网页提示「需要刷新控制台」时，可先复制未保存的内容或下载游戏配置草稿，再点一次「刷新页面」加载新版。更多检查、采集及开发命令见 [开发与辅助命令](docs/console-guide.md#开发与辅助命令)。
