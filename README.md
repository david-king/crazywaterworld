# 疯狂水世界 · 航行控制台

![Node.js 22.12+](https://img.shields.io/badge/Node.js-22.12%2B-417E38) ![Windows](https://img.shields.io/badge/Windows-本地控制台-0078D4) [![仅供学习交流](https://img.shields.io/badge/license-Study%20Only-orange)](LICENSE)

在本机管理《疯狂水世界》账号，直连游戏 WebSocket，安排领奖、基地经营、英雄养成和舰队任务。支持多账号独立配置、资源预算和运行日志，主要面向 Windows，提供 macOS 基础运行适配。

[快速开始](#快速开始) · [功能一览](#功能一览) · [常用命令](#常用命令) · [使用指南](docs/console-guide.md) · [更新日志](CHANGELOG.md)

## 快速开始

### 1. 安装环境并下载项目

安装 **Node.js 22.12 或更高版本**（也兼容 20.19+ 的 20.x）和 Git，重新打开终端后执行：

```powershell
git clone https://github.com/xutongxue233/crazywaterworld.git
cd crazywaterworld
```

也可下载仓库 ZIP 并解压。Windows 一键启动脚本会自动检查并安装项目依赖，无需提前执行 npm 安装命令。项目已通过 `.npmrc` 默认使用 npmmirror 境内镜像，一键启动和手动安装均生效。

### 2. 准备游戏协议文件（必需）

仓库不附带游戏协议，**缺少协议文件时控制台无法启动**。任选一种方式准备：

- **本机微信缓存**：在电脑版微信中完整进入一次《疯狂水世界》，等待游戏加载完成后退出游戏，工具会自动读取缓存。
- **自备协议包**：将 `_src_chunks_.wxapkg` 放到项目根目录（与 `package.json` 同级）或 `protocol/` 子目录。

本机微信缓存优先于自备包；若最新微信包缺分包或已损坏，请重新完整加载游戏，或用 `CW_PROTO_BUNDLE` 显式指定可用协议文件。[指定路径与 macOS 权限说明](docs/console-guide.md#启动与排查)

微信扫码、支付宝和 APP 登录也需要先准备协议。配置表和世界地图会从游戏 CDN 自动更新，协议文件仍需通过上述方式提供。

### 3. 启动控制台

**Windows：** 双击项目根目录的 `start-console.cmd`，或在终端执行：

```powershell
.\start-console.cmd
```

脚本会检查 Node.js 版本和 npm，按需安装依赖（包含界面构建工具），构建界面后启动控制台。首次安装需要联网；依赖完整且与锁文件一致时跳过安装。启动后手动打开终端显示的地址，默认为 [http://127.0.0.1:17323/](http://127.0.0.1:17323/)。任何一步失败都会停止并显示原因。

**macOS 或手动启动：** 在项目根目录执行：

```sh
npm ci --include=dev
npm start
```

`npm start` 构建界面后尝试打开浏览器，默认地址为 [http://127.0.0.1:17321/](http://127.0.0.1:17321/)。两个入口均支持 `CW_PORT`，以终端显示的地址为准。[启动参数与入口差异](docs/console-guide.md#启动参数)

### 4. 添加账号并开启挂机

1. 打开 **账号 → 添加账号**，选择微信扫码、支付宝、益世界 APP、电脑微信或电脑抖音采集，按提示登录并保存角色；已有备份可使用 **导入账号**。
2. 新账号的挂机、模块和细项开关默认全部关闭。在 **挂机配置** 中开启需要的项目、设置资源限制；活动专属设置在 **活动** 对应详情中调整。可先用 **只读预览** 查看计划。
3. 点击账号卡片或页头的 **开始挂机**。网页可关闭，请保持启动窗口打开、电脑唤醒；关闭启动窗口或按 `Ctrl+C` 会结束进程。

电脑微信和电脑抖音采集仅适用于 Windows；采集就绪后需从对应客户端重新进入游戏。支付宝扫码会优先复用已有浏览器，找不到时才自动下载 Chromium。[各渠道登录步骤](docs/console-guide.md#添加账号与抓包)

## 功能一览

| 分组 | 主要功能 |
| --- | --- |
| 基地与生产 | 建筑、工厂、农田、智能排产规划（支持工厂升级期间生产及普通月卡双生产位）、贸易港、居民订单、采集与钓鱼 |
| 英雄与养成 | 英雄培养与任命、自定义阵容（可从游戏推荐搭配一键布阵）、藏品、海兽、博物馆、装备制造与锻造 |
| 世界与挑战 | 资源田按比例或配额占领、自动换高级田、海盗首杀与扫荡、世界 Boss、货轮类型多选与奖励筛选（全部、任一或至少 N 项命中，中小船兜底可独立配置）、城战、主线与试炼 |
| 联盟与硅矿 | 募兵与互助、工事捐赠、联盟情报、舰队硅矿配置 |
| 日常与活动 | 竞技场和跨服积分赛可分别设置对手战力上限（占己方战力的百分比）、选人策略和留券数，完成每日挑战后停止。积分赛还可单独开启累计收集和战令领奖。另含邮件与奖励、礼包兑换、周期及限时活动。海商王按同盟船到港顺序和库存估算抢货收益 |
| 多账号与工具 | 独立配置和预算、账号导入导出、运行日志、世界地图点城驻防、增援、募兵与联盟集结/宣战 |

具体入口、玩法限制和执行规则见 [控制台使用指南](docs/console-guide.md#功能一览)。

在 **总览 → 资源田概览** 点击「查看明细」查看该类全部已占田，按行选择「放弃」。点卡片上的「占领」或「换田」可查看该类全部候选田，每行显示所属城市、等级和建筑名。需要替换时，先点新田所在行的「替换」，再选择旧田。三个列表均按等级从高到低排列。[资源田玩法与策略](docs/resource-fields.md)

城战接续出战没有每日次数上限。多盟同攻时，若攻方队列为空，或已同步的排队舰队明细与攻方队列总数吻合，城战接续可按本盟队数选城。若本盟队数仍无法确认，「按队数与距离选择」会跳过该城，「沿用集结／指定城市顺序」仍可按顺序派舰。

联盟募兵入口为 **挂机配置 → 世界 → 联盟 · 募兵与互助 → 自动在联盟城市募兵**，需同时开启联盟自动化总开关。新赛季没有专属次数配置时沿用不高于当前赛季的最近赛季配置，再按玩家等级取档；异常配置会停止募兵。[规则说明](docs/alliance-automation.md)

## 配置与预算

- 配置按账号自动保存，保存配置不会开始挂机。**暂停挂机** 停止循环并保留连接；自行进入游戏前使用 **暂停托管**，退出游戏后再 **恢复托管**。
- **钻石总开关默认关闭**，每日总预算默认 `2000`，保留量默认 `0`；日预算为 `0` 时禁止自动花钻石，各玩法限制与总预算同时生效。
- 用量和结果未知的操作会持久记录，重启或保存配置不会清空。自动恢复、配置修复和多页面冲突处理见 [配置与预算细则](docs/console-guide.md#配置与预算)。
- 舰队显示「情报占用待核对」时，控制台会复查原情报和该舰队。派遣超过 15 分钟仍未确认，且原情报仍待处理或已消失、舰队在主城空闲时，会自动释放舰队。原情报不会重复派遣，汽油仍列为待确认。

## 数据与问题排查

`data/` 保存账号凭据、设置、账本和日志，更新或迁移前请备份；账号导出文件也含登录信息，请留在本机。遇到启动失败，先看 [启动与排查](docs/console-guide.md#启动与排查)；功能执行异常按 [问题反馈日志](docs/console-guide.md#问题反馈日志) 保留记录。

请只用自己的账号测试。自动化操作会改变游戏资源和进度，第三方工具存在账号处罚风险。电脑客户端采集会临时修改 Windows 用户代理和证书，异常残留可按 [采集异常恢复](docs/console-guide.md#采集异常恢复) 处理。控制台没有登录校验，默认仅监听本机；开放其他接口时请使用可信局域网或带鉴权的隧道。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `.\start-console.cmd` | Windows 一键检查环境、按需安装依赖、构建并启动，默认端口 `17323` |
| `npm start` | 构建界面并启动控制台，默认端口 `17321` |
| `npm run build:ui` | 单独构建页面与样式 |
| `npm run sync-resources` | 立即检查并更新配置表和世界地图 |
| `npm run test:startup` | 检查启动准备、协议来源、监听地址与终端输出，无需游戏账号或真实协议包 |
| `npm run test:offline` | 构建、类型检查并运行核心离线回归，无需本机游戏协议包 |

更新项目时先停止控制台，备份 `data/`，更新源码后重新运行一键启动脚本；手动启动则重新执行 `npm ci --include=dev`、`npm start`。已打开的网页提示「需要刷新控制台」时，可先复制未保存的内容或下载游戏配置草稿，再点一次「刷新页面」加载新版。更多检查、采集及开发命令见 [开发与辅助命令](docs/console-guide.md#开发与辅助命令)；完整 `npm test` 需要本机游戏协议包。
